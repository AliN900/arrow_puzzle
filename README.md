# Arrow Puzzle: Tap Maze Escape

A clean, modern grid-based puzzle game where every tap counts. Tap arrows to guide them through the maze — an arrow moves only when its path is clear, so the order you choose matters. 

This is a native Android (Kotlin) rewrite and expansion of the original open-source Flutter game *ArrowEscape*.

## 🎮 Game Features
- **Grid-Based Puzzle:** Tap arrows to move them. An arrow only moves if its path is clear.
- **Infinite Levels:** Procedurally generated puzzles ensure you never run out of challenges.
- **Minimalist Design:** Clean visuals and crisp effects designed to help you focus.
- **100% Offline:** Play anywhere without needing an internet connection.

## 🛠️ Tech Stack
- **Language:** Kotlin
- **Platform:** Android (Native Android Studio)
- **Architecture:** MVVM (or whatever you're using)

## 🚀 Getting Started
To build and run this project locally:
1. Clone this repository.
2. Open the project in Android Studio.
3. Build the project and run it on an Android emulator or physical device.
