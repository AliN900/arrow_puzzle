# Arrow Puzzle: Tap Maze Escape

A clean, modern grid-based puzzle game where every tap counts. Tap arrows to guide them through the maze — an arrow moves only when its path is clear, so the order you choose matters.

This is a Flutter fork and expansion of the original open-source game [ArrowEscape](https://github.com/sidhant947/ArrowEscape), redesigned with a new UI, theme system, and additional features.

## 🎮 Game Features

- **Grid-Based Puzzle:** Tap arrows to move them. An arrow only moves if its path is clear.
- **Infinite Levels:** Procedurally generated puzzles ensure you never run out of challenges.
- **Multiple Game Modes:** Classic, Zen, Time Attack, and Multiplayer seed sharing.
- **Themes & Custom Skins:** Multiple color themes with an accent color picker.
- **Light & Dark Mode:** Full theme support with an in-app toggle.
- **Minimalist Design:** Clean visuals and crisp effects designed to help you focus.
- **100% Offline:** Play anywhere without needing an internet connection.

## 🛠️ Tech Stack

- **Framework:** Flutter
- **Language:** Dart
- **State Management:** Riverpod
- **Local Storage:** Hive
- **Game Engine:** Flame
- **Platforms:** Android, iOS
